# TRAVELIQ Data Sources

This document records the sources, licensing,
methodology and provenance of data used by TRAVELIQ.

## Data Classification

### Static Data

Information that does not change frequently.

Examples:
- Country
- Country code
- Coordinates
- Currency

### Estimated Data

Values calculated or estimated using documented methodology.

Examples:
- Average daily travel cost
- Accommodation cost
- Food cost
- Activity cost

### Live/API Data

Information retrieved dynamically from an external API.

Examples may include:
- Currency exchange rates
- Weather information
- Other real-time travel information

## Sources
